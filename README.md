# 🐶 TinDog – Tinder for Dogs

**Live Site:** [kenechukz.github.io/TinDog](https://kenechukz.github.io/TinDog/)

## 📄 Project Overview

TinDog is a responsive, single-page marketing site for a fictional dog dating app—“Tinder for Dogs.”  
Inspired by modern tech startups, this website was built to practice responsive design, Bootstrap layout techniques, and basic UI/UX principles.

This project was part of my journey to solidify core **HTML**, **CSS**, and **Bootstrap** skills while creating a clean, mobile-friendly interface with reusable components.

---

## 🧰 Tech Stack

| Frontend        | Framework / Tools |
|----------------|--------------------|
| HTML5          | Bootstrap 5        |
| CSS3           | GitHub Pages       |
| Google Fonts   | Font Awesome       |

---

## 🎯 Features

- 🚀 Sleek, mobile-first design
- 📱 Responsive layout built entirely with Bootstrap grid
- 🎨 Custom buttons, card components, and pricing sections
- 🌈 Clean typography and brand styling with Google Fonts
- 📦 Icons and badges via Font Awesome
- ☁️ Hosted live via GitHub Pages

---

## 🖼️ Sections Overview

- **Header / Hero** – Logo, app download links, and value proposition
- **Features** – Key selling points and benefits
- **Testimonials** – Social proof from happy (dog) users
- **Pricing** – Plan options using cards
- **Footer** – Company links and copyright
